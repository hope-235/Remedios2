# RemediosRing 💊

App de recordatorio de medicamentos con notificaciones inteligentes.

## Funcionalidades

- ✅ Agregar remedios con nombre, dosis, tipo y hora
- 🔔 Notificaciones 2 minutos antes y 2 minutos después de la hora
- 🔁 Frecuencia configurable (cada 4, 6, 8, 12 o 24 horas)
- 📦 Control de inventario con alerta de stock bajo
- 💾 Guardado local persistente (no se pierden al cerrar la app)
- 🎨 Iconos personalizados por tipo de remedio (pastilla, jarabe, gotas, inyección)
- ✅ Botón "Ya lo tomé" y "Posponer 10 min" directo en la notificación

## Cómo obtener el APK

1. Subí todo el contenido de esta carpeta a un repositorio de GitHub
2. Andá a la pestaña **Actions**
3. El workflow se ejecuta automáticamente y genera el APK
4. Descargalo desde los **Artifacts** del workflow completado
